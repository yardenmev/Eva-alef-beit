# Eva Alef Beit - משחקי אותיות לאווה

משחקי אינטרנט ללימוד הא״ב העברי: שביל האותיות, רכבת האותיות, זוגות, בועות ועוד.

## לשחק
https://yardenmev.github.io/Eva-alef-beit/

## מה יש בריפו
- `app/` - קוד המקור הניתן לעריכה (React + TypeScript + Vite), עם פקודות התקנה ובנייה. מתחילים מ-[app/README.md](app/README.md).
- `index.html`, `main.js`, `assets/` בשורש - הגרסה הבנויה שהאתר החי מגיש כרגע. לא עורכים אותם ידנית; הם נוצרים מ-`app/` בפקודה `npm run publish-site` (מתוך `app`). אחרי פרסום עתידי שם הקובץ `main.js` יוחלף בקובץ JS בתוך `assets/`.

## להמשיך לפתח
מדריך בעברית, מותאם לעבודה מהטלפון עם סוכן קוד: [app/GUIDE_HE.md](app/GUIDE_HE.md).

ההתקדמות במשחק נשמרת בדפדפן של המכשיר.
