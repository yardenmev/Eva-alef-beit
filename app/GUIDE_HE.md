# איך ממשיכים לעבוד על המשחק מהטלפון

## הרעיון
- הקוד נמצא בתיקייה `app` בריפו https://github.com/yardenmev/Eva-alef-beit
- האתר החי הוא הקבצים בשורש הריפו (`index.html`, `main.js`, `assets/`). הם נוצרים מהקוד שב-`app`, ולא משתנים עד שמפרסמים בכוונה.
- זרימת עבודה: משנים קוד ב-`app/src`, בודקים בתצוגה מקדימה, מפרסמים, דוחפים ל-GitHub.

## לפני שמתחילים
צריך מכונה עם Node.js 20 ומעלה וגיט, למשל ה-VM שלך ב-GCP (אם Antigravity עדיין מוגדר שם - צריך לוודא). כל פקודות npm רצות **מתוך תיקיית app**, לא משורש הריפו.

הדבקה לסוכן (Antigravity) בפעם הראשונה:

> שכפל את https://github.com/yardenmev/Eva-alef-beit (אם כבר משוכפל, עשה git pull). היכנס לתיקייה app והרץ `npm ci`. אל תשנה כלום עדיין, ותאשר לי שהפקודה הצליחה.

## שינוי ראשון לדוגמה
הדבקה לסוכן:

> ב-app/src/App.tsx שנה את הכותרת `<Header title="המשחקים של אווה"/>` ל-`<Header title="המשחקים של אווה 🦁"/>`. מתוך app הרץ `npm run build` וודא שאין שגיאות.

## לראות את השינוי לפני פרסום
הדפדפן בטלפון לא יכול לפתוח `localhost` של ה-VM. אל תפתחו פורט ציבורי בלי הגנה. האפשרויות, לפי סדר העדפה:
1. אם Antigravity מציע תצוגה מקדימה מוגנת (דורשת התחברות) - להשתמש בה. לא בדקנו שיש כזו, אז צריך לשאול את הסוכן.
2. אחרת: מנהרה שדורשת הזדהות (לא קישור פתוח לכולם), שהסוכן מגדיר ומסביר לך לפני שהוא מריץ אותה.
3. או לבקש מהסוכן צילומי מסך של המשחק אחרי השינוי (תצוגת טלפון 390x844) ולבדוק אותם.

## לפרסם
אחרי שאישרת את התוצאה, להדביק לסוכן:

> מתוך app הרץ `npm run publish-site`. זה מחליף בשורש הריפו את index.html ואת assets/ ומוחק את main.js הישן, והבנייה החדשה יוצרת קובץ JS עם שם מגובב בתוך assets/. הראה לי git status: צריכים להשתנות רק השינויים שביקשתי ב-app/src, והקבצים שנוצרו בשורש (index.html, assets/, main.js שנמחק). אם יש עוד קבצים, עצור ותשאל אותי. אחר כך עשה commit בעברית קצרה ודחוף ל-GitHub.

שימו לב: הפרסום משנה את מה שהאתר החי מגיש, ולכן עושים אותו רק כשרוצים. GitHub Pages מתעדכן בדרך כלל תוך דקות ספורות, לפעמים יותר. אחרי זה פותחים את https://yardenmev.github.io/Eva-alef-beit/ ומרעננים. כדאי לבדוק משחק אחד וסאונד אחד בטלפון.

## כללי זהירות
- הקלטות חדשות: אווה שומעת אותן, אז קודם מאזינים ומאשרים לפני שמפרסמים.
- אם משהו נשבר: `git log` מראה גרסאות קודמות, ואפשר לבקש "תחזיר את הקבצים בשורש לגרסה הקודמת".
- אל תכניסו סיסמאות, מפתחות או קבצי `.env` לריפו הציבורי.
